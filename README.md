# sphrd's Homebrew tap

```sh
brew install --cask sphrd/tap/spacepie
```

[SpacePie](https://sphrd.github.io/SpacePie/): the fastest free disk space analyzer and cleaner for Windows and macOS. Open source ([sphrd/SpacePie](https://github.com/sphrd/SpacePie)).

The cask always installs the latest release; the app then updates itself.
